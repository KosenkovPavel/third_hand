# Руководство пользователя

## Первый запуск: визард настройки

`python main.py` без аргументов открывает TUI. Если `data/profile.json` нет,
запускается визард из трёх шагов (везде Enter = рекомендуемое):

1. **Стратегия портфеля.** Бытовые варианты («Хочу много денег и поменьше
   риска» → сбалансированная 50/30/20 акции/облигации/золото) или другой
   пресет, или своя структура вручную.
2. **Пополнения.** Сколько ₽/мес готовы откладывать — нужно для прогноза
   и оценки вычета ИИС. Можно пропустить.
3. **Скрининг акций.** На что ориентироваться при подборе бумаг
   (дефолт — сбалансированный набор); экспертный режим — свои метрики.

Настройки — не навсегда: команда `настройка` в TUI перезапускает визард
(остальные поля профиля сохраняются), либо правка `data/profile.json`
(все поля с комментариями — в `data/profile.example.json`).

## TUI (по умолчанию)

Кнопки: Портфель · Ребаланс · ИИС · Прогноз · История · Риски · Детально.
Текстовые команды: `рынок`, `календарь`, `новости`, `акции`, `облигации`,
`стресс`, `цель`, `настройка`, `выход`.

## Все команды CLI

| Команда | Что делает |
|---|---|
| `python main.py` | TUI |
| `--account ID` | другой счёт (по умолчанию из .env) |
| `--rebalance [JSON]` | план под цель из профиля или под JSON `{"Акции": 60, "Облигации": 40}` |
| `--invest N` | пополнение сверх остатка (для плана) |
| `--forecast` | прогноз роста + сценарии |
| `--monthly N` / `--return %` | параметры прогноза |
| `--risk` | концентрация и риски |
| `--market` | консенсус аналитиков, инсайдеры, RSI |
| `--history` | история снимков и проверка рекомендаций |
| `--calendar` | календарь дивидендов/купонов на год |
| `--stress-test` | повтор кризисов 2008–2022 на вашем портфеле |
| `--mc` | Монте-Карло: шансы достичь целей из профиля |
| `--screen JSON` | скринер акций: `{"pe_max": 10, "div_min": 5, "roe_min": 12}` |
| `--bonds JSON` | подбор облигаций: `{"ytm_min": 11, "coupon_min": 9}` |
| `--picks JSON` | подбор акций: `{"score_min": 65, "top_n": 15}` |
| `--goal JSON` | траектория к пенсии: `{"income": 100000, "withdraw": 4, ...}` |
| `--tax ГОД` | справка 3-НДФЛ за год в `data/` |
| `--save` | снимок портфеля в `data/portfolio.json` |
| `--telegram` | сводка в Telegram (нужны токен и chat id в .env) |
| `--history-days N` | глубина анализа операций |
| `--stress` | стресс-режим подбора акций (защитные сектора) |

## MCP: ИИ-агент на ваш выбор

```bash
python -m src.frontends.mcp
```

Подключение (пример для Claude Code):
`claude mcp add third-hand -- .venv/bin/python -m src.frontends.mcp`

Инструменты (read-only): `portfolio_report`, `rebalance_plan`, `xirr`,
`iis_deductions`, `forecast`, `tax_report`. Готовый системный промпт для
агента — `docs/agent_prompt.md`; сценарий проверки диалога —
`docs/demo_dialogue.md`.

## Блок «для аналитика»

Как использовать отчёт в работе с клиентом:

1. **Сверка P&L с брокером** в полном отчёте — покажите клиенту, почему его
   «минус» по облигациям — это НКД, а не ошибка: доверие через объяснение.
2. **Блок «Самопроверка»** — ваш трек-рекорд: hit rate рекомендаций против
   IMOEX и журнал сигналов. Работает на доверие лучше любых обещаний;
   при малом количестве данных система честно пишет «мало данных».
3. **Стресс-тест** — наглядный ответ клиенту «а что если кризис?» на его же
   позициях, и рядом поведение сбалансированной стратегии в том же окне.
4. **Монте-Карло к цели** — разговор о целях клиента в вероятностях,
   а не в обещаниях: «при текущем темпе шанс N%, рычаги — взнос и срок».
5. **Справка 3-НДФЛ** (`--tax ГОД`) — готовый документ для клиента одной
   командой; дедлайны и сгоревшие вычеты посчитаны.
