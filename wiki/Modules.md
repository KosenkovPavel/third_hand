# Модули ядра (`src/`)

Как работает каждый модуль, по группам. Слой и правило: ядро возвращает
датаклассы, SDK брокера напрямую не импортирует никто, кроме провайдера.

## Модель и деньги

- **`portfolio.py`** — каноническая модель: `Position`, `PortfolioSnapshot`,
  `Allocation`. Здесь же классификация инструментов по классам
  (`classify_position`): индексные ETF относятся к своему классу
  (`TMOS`→Акции, `SUGB`→Облигации, `TGLD`→Золото), фьючерсы на золото —
  в «Золото». Реестр `CLASS_ETF_TICKERS` — инструменты «по умолчанию»
  для исполнения целевой структуры.
- **`money.py`** — конвертация `MoneyValue`/`Quotation` (units+nano) в
  `Decimal`. Все деньги в проекте — `Decimal`, никогда `float`.

## Профиль и стратегия

- **`profile.py`** — профиль пользователя (`data/profile.json`): целевая
  структура, пополнения, ИИС, правила дисциплины (лимиты позиции/сектора),
  веса скоринга. Здесь же `STRATEGY_PRESETS` — пресеты из бэктеста
  (balanced 50/30/20 — дефолт, classic, conservative, aggressive, income)
  с пояснениями для визарда.
- **`rebalance.py`** — распределение нового пополнения под целевую структуру:
  сколько направить в каждый недовешенный класс. Продажи не предлагаются —
  только новые деньги.
- **`contribution_plan.py`** — виртуальный план покупок по лотам: жадное
  распределение бюджета по кандидатам с учётом лотов, комиссии и лимитов
  (позиция/сектор). `load_purchase_candidates` — кандидаты из текущих
  позиций (прошедшие рекомендацию и фильтр риска), `load_default_candidates` —
  индексные ETF по целевым классам, чтобы план был исполним даже с нуля.
- **`metrics.py`** — каталог фундаментальных метрик (P/E, ROE, дивдоходность,
  долг и др.): правило «значение → баллы 0–100». `DEFAULT_WEIGHTS` — дефолтный
  скоринг, `SCORING_STYLES` — стили (дивидендный, недооценка, качество, рост,
  спокойствие), `SCORING_PLAIN_OPTIONS` — их бытовые варианты для визарда.
- **`analytics.py`** — фундаментальный анализ позиций: оценка 0–100 и
  рекомендация («Покупать»/«Держать»/…) по мультипликаторам, стресс-тилт
  секторов, правила из профиля.

## Бухгалтерия и налоги

- **`accounting.py`** — анализ операций: денежный поток, внесено/выведено,
  комиссии, налоговая база, средний месячный приток.
- **`iis.py`** — ИИС: вычеты на взносы по годам (лимит 400 тыс., возврат 13%),
  прогресс к лимиту, незаявленные и сгоревшие годы с дедлайнами, срок
  владения ИИС-3, справка 3-НДФЛ.
- **`xirr.py`** — годовая доходность (money-weighted) с учётом дат и сумм
  взносов. Показывается только для счетов старше 3 лет — на коротком
  горизонте XIRR обманчив.

## Риски и сигналы

- **`risk.py`** — концентрация (инструменты/сектора/классы, β), категории
  облигаций (ОФЗ/корпоративные/ВДО), сигналы дисциплины из правил профиля.
  Здесь же `crisis_buy_signal` — правило «кризисного откупа»: просадка
  индекса от 12-мес максимума глубже −30% → режим откупа, выход выше −15%.
- **`signal_journal.py`** — журнал сигналов откупа (append-only
  `data/signal_journal.jsonl`): фиксация факта с датой и оценка созревших
  (90+ дней) сигналов против IMOEX. Основа самопроверки.
- **`recommendation_history.py`** — журнал рекомендаций акций и оценка их
  результата против IMOEX через 90/180/365 дней; `hit_rate_summary` —
  доля рекомендаций, обогнавших индекс (честное «мало данных» < 5 исходов).
- **`stress_test.py`** — повтор кризисов 2008/2014/2020/2022 на текущем
  портфеле по дневным свечам (fallback на индексы классов и research-ряды
  для старой истории) и сравнение со стратегией 50/30/20.
- **`montecarlo.py`** — персональный Монте-Карло: block bootstrap (12 мес)
  по историческим доходностям классов, веса — текущая структура, взносы —
  из профиля. Вероятность достижения целей в реальных рублях.

## Подбор инструментов

- **`screener.py`** — поиск акций по фильтрам (P/E, дивдоходность, ROE…) по
  универсуму RUB-акций MOEX или списку тикеров.
- **`picks.py`** — подбор акций к покупке: двухфазный скрининг
  (фундаментальная оценка + бленд с потенциалом аналитиков и RSI), контекст
  портфеля («докупка»/«новая»).
- **`bonds.py`** — скринер облигаций: YTM как IRR по фактическому графику
  купонов до погашения (бисекция), фильтры по риску.

## Прогнозы и цели

- **`forecast.py`** — прогноз стоимости: сложный процент + пополнения,
  три сценария, альтернатива «вклад под ключевую», реинвестиция вычета ИИС,
  реальные деньги с поправкой на инфляцию.
- **`goals.py`** — траектория к пенсии: цель в реальном капитале
  (расходы × 12 / норма изъятия), оценка «успеваете ли» при текущем темпе,
  статусы целей из профиля.
- **`simulation.py`** — контрольная симуляция: те же денежные потоки
  пользователя, но вложенные в индекс IMOEX (сравнение «активный портфель
  против просто индекса»).

## Рынок и фон

- **`market.py`** — мнение рынка: консенсус аналитиков, сделки инсайдеров,
  RSI позиций.
- **`macro.py`** — ключевая ставка ЦБ (SOAP-сервис, кэш на день),
  доходность вклада за период.
- **`calendar.py`** — календарь будущих выплат (дивиденды/купоны) по позициям
  на 12 месяцев.
- **`news.py`** — новостной фон без внешних API: дельты целей аналитиков
  между запусками, инсайдеры, RSI-перегрев, отсечки; опционально RSS.
- **`history.py`** — история снимков портфеля: накопление точек, мини-график,
  TWR.

## Инфраструктура

- **`config.py`** — пути (`data/`), токены (.env), креды Telegram.
- **`backup.py`** — ротационные бэкапы файлов данных перед перезаписью.
- **`notify.py`** — отправка сводки в Telegram (Bot API, urllib).
- **`report_data.py`** — `ReportData`: единый контракт «вычисление →
  отображение» для всех фасадов.
- **`report_builder.py`** — `build_report()` / `build_multi_report()`:
  оркестрация всех вычислений (параллельная сеть на границах), `ReportError`.
- **`report.py`** — rich-рендер отчёта (`print_all` + простые/детальные
  варианты для TUI).

## Фасады (`src/frontends/`)

- **`cli.py`** — argparse-фасад: все флаги (`--rebalance`, `--forecast`,
  `--risk`, `--stress-test`, `--mc`, `--tax`, `--telegram` и др.),
  побочные эффекты (`--save`, отправка сводки).
- **`tui.py`** — Textual-фасад: запуск без аргументов, визард первой
  настройки (стратегия → взносы → скрининг), команда «настройка»,
  фоновое обновление базы, режимы «просто/детально».
- **`mcp.py`** — MCP-сервер (FastMCP, read-only): 6 инструментов —
  `portfolio_report`, `rebalance_plan`, `xirr`, `iis_deductions`, `forecast`,
  `tax_report`. Отдаёт агенту готовые вычисления + `crisis_signal` и
  `self_validation`.

## Провайдеры (`src/providers/`)

- **`protocols.py`** — три протокола (`AccountClient`, `MarketDataClient`,
  `AnalyticsClient`): контракт для любого брокера.
- **`tinkoff.py`** — адаптер Т-Инвестиций: сбор снапшота (включая
  НКД-математику и классификацию ETF по классам), операции, свечи,
  фундаменталки, консенсус/инсайдеры/RSI.
