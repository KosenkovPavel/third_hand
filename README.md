## Для кого этот проект

- **Начинающим инвесторам.** Не нужно разбираться в метриках и структуре портфеля:
  при первом запуске вас спросят два вопроса бытовым языком, а дефолтная стратегия
  уже проверена на 23 годах российского рынка.
- **Продолжающим (DIY).** Глубина, которой нет в приложении брокера: честный P&L
  с разбором НКД, доходность XIRR, вычеты ИИС до рубля, скринеры акций и
  облигаций, стресс-тест портфеля на кризисах 2008–2022.
- **Личным аналитикам и советникам.** Готовые отчёты по портфелю клиента и
  публичный трек-рекорд рекомендаций — советник показывает свою точность,
  а не просит верить на слово.

## Какую проблему решает

Приложение брокера отвечает на вопрос «сколько у меня денег», но не отвечает
на главный — **«что делать и почему»**. При этом его цифры вводят в заблуждение:
«цена минус средняя» по облигациям игнорирует накопленный купон (НКД), вычеты
ИИС теряются из-за незнания дедлайнов, а советы из телеграм-каналов не подкреплены
ничем. «Третья рука» закрывает всё это дома, на вашей машине: данные и токены
никуда не отправляются.

## Что умеет

- **Честные цифры до копейки** — доход разложен на реализованный, нереализованный,
  купоны/дивиденды и комиссии; по облигациям показываем расхождение с наивным
  расчётом и объясняем его НКД.
- **Стратегия с доказательством** — целевая структура не нарисована: проверена на
  данных MOEX и ЦБ с 1997 года (бэктесты, Монте-Карло, walk-forward). Дефолт —
  сбалансированная 50/30/20 (акции/облигации/золото).
- **План покупок по лотам** — что купить на следующее пополнение под вашу цель;
  исполним даже с пустого портфеля (индексные ETF по умолчанию).
- **Налоги ИИС без головной боли** — прогресс до лимита 400 тыс., незаявленные
  и сгоревшие вычеты, дедлайны, справка 3-НДФЛ одной командой.
- **Стресс-тест и шансы цели** — повтор кризисов 2008/2014/2020/2022 на ваших
  позициях и вероятность достичь целей по Монте-Карло, без обещаний.
- **Сигнал «кризисный откуп»** — единственное правило тайминга, прошедшее
  статистическую проверку: просадка индекса глубже 30% — время взносов в акции.
- **Самопроверка советника** — журнал рекомендаций и сигналов с оценкой против
  индекса: система показывает собственный трек-рекорд.
- **ИИ-агент на ваш выбор** — MCP-сервер: любой агент (Claude, ChatGPT, GigaChat)
  получает готовые вычисления и объясняет их вам.

## Быстрый старт

Требуется Python 3.12+ и токен Т-Инвестиций (раздел «Разработчикам» в приложении).

```bash
git clone https://github.com/KosenkovPavel/third_hand.git
cd third_hand
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # вписать TINKOFF_TOKEN и ACCOUNT_ID
python main.py         # визард первой настройки, затем отчёт
```

Дальше: `python main.py --rebalance --invest 10000` — план покупок,
`--stress-test` — кризисы на вашем портфеле, `--mc` — шансы целей,
`--help` — все команды.
